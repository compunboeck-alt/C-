# 俄罗斯方块

这是一个基于 C# 和 WinForms 实现的俄罗斯方块游戏。

## 环境要求

- Windows 10 或更高版本
- .NET 10 SDK
- Visual Studio 2022 或 Visual Studio Code
- VS Code 需要安装 C# Dev Kit 扩展

## 项目结构

- `Tetris.Core`：游戏核心逻辑
- `Tetris.app`：WinForms 界面和键盘输入
- `Tetris.Core.Tests`：xUnit 单元测试
- `Tetris`：控制台项目
